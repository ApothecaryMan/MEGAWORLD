# Coding Style & Design Rules

## UI/UX Standards (Pure Flat)
- **No Shadows**: Never use `box-shadow` or `text-shadow`.
- **No Transitions**: Never use `transition` or `animation`. All UI changes must be instant.
- **Borders**: Use `1px` borders for separation.
- **RTL Support**: Always support Arabic (RTL) layout using logical properties.
- **Variables**: Always use CSS variables from `style.css` for colors and fonts.

## Tech Stack
- HTML, CSS, Vanilla Javascript.
- Custom Store for state management (`store.js`).
- Modular Toolbar Engine (`toolbar.js`).
